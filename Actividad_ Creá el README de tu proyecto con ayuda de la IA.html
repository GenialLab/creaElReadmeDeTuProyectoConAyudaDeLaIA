¡Creá el README de tu proyecto con ayuda de la IA!

Una actividad paso a paso para llevar lo aprendido a la práctica: de la idea al repositorio en GitHub.

Objetivo

Utilizar una herramienta de inteligencia artificial para elaborar un archivo README en formato Markdown, reconociendo su función como documento de presentación y descripción de un proyecto en un repositorio de GitHub.

¿En qué consiste?

Los archivos README permiten presentar un proyecto, explicar cuál es su propósito y describir sus principales características. Vas a usar una herramienta de IA para crear una primera versión de este documento.

Recorrido

1. Elegí un proyecto · 2. Definí tu idea · 3. Trabajá con la IA · 4. Llevá tu README a GitHub · 5. Compartí tu producción

1. Elegí un proyecto

Seleccioná una de las propuestas. No necesitás programar ni desarrollar el proyecto: solamente imaginar en qué consiste y cuáles serían sus principales funcionalidades.

2. Definí tu idea

Antes de utilizar la IA, pensá y describí brevemente tu proyecto. Indicá qué problema busca resolver, cuál es su propósito y qué funcionalidades te gustaría que tuviera.

Este paso es de reflexión: no hace falta escribir nada en esta página. Anotá tus respuestas en un borrador propio (un documento o el bloc de notas): las vas a usar en el paso siguiente.

Elegí ChatGPT, Gemini, Claude u otra herramienta de IA y usá este prompt. Reemplazá lo que aparece resaltado en naranja con la información de tu proyecto (lo que pensaste en el paso anterior) y pegalo en la herramienta.
